# GoalAlert Updates

Separater Update-Kanal fuer die GoalAlert-Enigma2-App (Vu+ Zero 4K / OpenATV).

## Status

Der Kanal ist eingerichtet. Der Online-Updater wird erst aktiviert, wenn ein geprueftes IPK-Paket mit HTTPS-Downloadadresse, Versionsnummer und SHA-256-Pruefsumme veroeffentlicht ist.

Der Update-Client soll das Paket vor einer Installation pruefen und die ausdrueckliche Bestaetigung am TV verlangen.

Keine IPTV-Zugangsdaten, Senderlisten mit Credentials oder Passwoerter hochladen.

Nova-IPTV und PlayerTrack-AI bleiben eigenstaendige Projekte.
